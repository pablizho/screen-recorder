\# 🖥️ Screen Recorder



Запись экрана с GUI интерфейсом на Python для Windows.



\## Возможности



\- 🖥️ Запись всего экрана / выбранного монитора

\- 📐 Запись выделенной области

\- 🪟 Запись конкретного окна

\- 🖱️ Запись системного курсора мыши

\- 💡 Подсветка кликов мыши (ЛКМ / ПКМ)

\- 🔊 Запись звука (микрофон)

\- ⌨️ Горячие клавиши (настраиваемые)

\- 🗜️ Сжатие через FFmpeg (H.264 / H.265 / AV1)

\- ⚙️ Настройка FPS, качества, кодека

\- ⏸️ Пауза / продолжение записи

\- 🚀 Быстрый режим без GUI



\## Требования



\- Windows 10/11

\- Python 3.10+

\- \[FFmpeg](https://www.gyan.dev/ffmpeg/builds/) (для сжатия)



\## Установка



1\. Клонируйте репозиторий:

```bash

git clone https://github.com/ВАШ-ЛОГИН/screen-recorder.git

cd screen-recorder 

2\. Установите зависимости:

pip install -r requirements.txt 

Или запустите install_deps.bat

3\. Установите FFmpeg и добавьте в PATH 

Использование
GUI версия
Bash

python recorder.py
Или запустите start_recorder.bat

Быстрая версия (без GUI)
Bash

python quick_record.py
